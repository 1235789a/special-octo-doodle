# 第2阶段：用户导出流程设计

## 一、导出流程文档

### 1.1 Windows 版本

#### 前置条件
- Windows 7/10/11
- 微信 PC 版已安装并登录
- 微信数据已同步到本地

#### 操作步骤

| 步骤 | 操作 | 说明 |
|-----|------|-----|
| 1 | 📂 打开微信数据目录 | `C:\Users\你的用户名\Documents\WeChat Files\你的微信号` |
| 2 | 📋 复制整个文件夹 | 选中 `你的微信号` 文件夹，Ctrl+C 复制 |
| 3 | 💾 粘贴到桌面 | 在桌面 Ctrl+V 粘贴，重命名为 `微信数据备份` |
| 4 | 📦 压缩文件夹 | 右键 → 发送到 → 压缩(zipped)文件夹 |
| 5 | ✅ 完成 | 生成的 `微信数据备份.zip` 就是我们需要的文件 |

#### 最终生成文件
`微信数据备份.zip`（包含 Msg、Misc、Contact 等文件夹）

---

### 1.2 macOS 版本

#### 前置条件
- macOS 10.14 及以上
- 微信 Mac 版已安装并登录
- 微信数据已同步到本地

#### 操作步骤

| 步骤 | 操作 | 说明 |
|-----|------|-----|
| 1 | 📂 打开 Finder | 点击 Dock 上的 Finder 图标 |
| 2 | 🔍 前往文件夹 | 按 `Command+Shift+G`，输入：`~/Library/Containers/com.tencent.xinWeChat/Data/Library/Application Support/com.tencent.xinWeChat/` |
| 3 | 📂 进入数据目录 | 进入那个长串字符命名的文件夹 → 再进入 `Message` 或类似目录 |
| 4 | 📋 复制整个文件夹 | 选中包含你的微信数据的文件夹，Command+C 复制 |
| 5 | 💾 粘贴到桌面 | 在桌面 Command+V 粘贴，重命名为 `微信数据备份` |
| 6 | 📦 压缩文件夹 | 右键 → 压缩"微信数据备份" |
| 7 | ✅ 完成 | 生成的 `微信数据备份.zip` 就是我们需要的文件 |

#### 最终生成文件
`微信数据备份.zip`

### 3.3 工具功能特性

| 功能 | 说明 |
|-----|------|
| 自动扫描 | 自动检测微信安装位置和数据目录 |
| 账号选择 | 支持多账号，用户可选择要导出的账号 |
| 群聊筛选 | 可选择特定群聊，避免导出全部数据 |
| 数据压缩 | 自动压缩导出数据，减小文件体积 |
| 隐私保护 | 所有数据本地处理，不上传云端 |

## 四、风险清单与应对方案

### 4.1 风险清单

| 风险项 | 说明 | 严重程度 | 应对方案 |
|-------|------|---------|---------|
| 微信目录找不到 | 用户可能不知道微信数据位置 | 🔴 高 | 工具自动扫描常见位置，同时提供手动选择功能 |
| 数据太大 | 微信数据可能有几个 GB，上传慢 | 🟡 中 | 只导出必要的数据库文件，压缩传输，支持增量导出 |
| 隐私担忧 | 用户担心数据安全 | 🟡 中 | 明确说明数据不上传云端，本地处理，开源代码 |
| 微信版本不兼容 | 新版本微信数据结构变化 | 🟡 中 | 及时更新工具，支持多版本微信 |
